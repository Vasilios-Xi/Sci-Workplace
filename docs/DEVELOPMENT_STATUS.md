# Sci Workplace Harness 开发进度

更新日期：2026-08-25

版本：`0.1.0` 开发快照

范围：对话端 Harness 本体

## 当前结论

Sci Workplace 已具备可运行的本地科研对话端、持久多 Agent、模型接入、工具审批、项目文件和 Electron 安全壳。当前迭代已完成对话界面的主体重构，并将旧工作台与旧内置插件从活跃产品界面和发布物中移出。

“工作台”导航入口继续保留，方便后续重新开发，但当前只打开明确的占位页。Runtime/Protocol 中仍有少量旧接口作为迁移兼容层；这些接口没有对应的活跃工作台 UI，也不会打包旧插件内容。

## 本次整理

- 产品可见名称、窗口标题、侧栏品牌、提示语、安装包和 GitHub 工程统一为 **Sci Workplace** / `Sci-Workplace`。

- 旧工作台界面和旧内置插件不进入源码发布范围；工作台仅保留导航入口和占位页。
- 安装包、解包目录、E2E 截图、视频、缓存、数据库、凭据和本机项目数据全部通过忽略规则排除。
